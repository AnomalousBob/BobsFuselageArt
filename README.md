This is a mod for Kerbal Space Program that adds __over 120 high quality decals__ to add flair and make your vessels more personal!
The mod features:
- Aircraft nose art
- Tracking patterns
- Rescue, danger, flair stencils
- Razzle Dazzle patterns
- Text and navigation stencils

Decals are separated by categories into conformal decal parts.

## Dependencies
- [Conformal Decals](https://forum.kerbalspaceprogram.com/topic/194802-conformal-decals-decals-done-the-right-way/)
- [B9 Part Switch](https://github.com/blowfishpro/B9PartSwitch)
